# Woolf Room of One's Own - IB Paper 1 Beamer Deck

108-slide Beamer presentation for IB English A: Literature on writing about nonfiction prose, using Virginia Woolf's *A Room of One's Own*.

## Compile on Overleaf

1. Create a new project on Overleaf (or import from GitHub).
2. Upload `woolf_room_paper1_beamer.tex` (or sync this repo).
3. Set the compiler to pdfLaTeX (or LuaLaTeX).
4. The Metropolis theme is available in Overleaf's TeX Live.
5. Compile.

The full .tex file is self-contained and ready to compile.

Source text reference: https://gutenberg.net.au/ebooks02/0200791h.html
